# Gym Tracker

Version: 0.1

A simple, offline-first gym tracking Progressive Web App with:

- Workout logging (strength + cardio)
- Progress charts (max weight, volume, estimated 1RM)
- Gamification (XP, levels, streaks, badges)
- Full FitNotes CSV import
- Your historical data pre-loaded and ready to import
- Export / import backup
- Dark mobile-friendly UI
- Works completely offline after first load (localStorage)

## How to put it on GitHub Pages

1. Create a new repository on GitHub (e.g. `gym-tracker`).
2. Upload **all files** in this folder to the repository (or push via git).
3. Go to **Settings → Pages**.
4. Under "Source", select the `main` branch and `/ (root)`.
5. Save. After a minute your app will be live at:
   `https://YOURUSERNAME.github.io/gym-tracker/`

You can also just open `index.html` directly in a browser for local use.

## First-time use

1. Open the app.
2. Go to the **Data** tab (gear icon).
3. Tap **Load My FitNotes Data (535 sets)** — this imports the data you provided.
4. Explore History, Charts, etc.

You can also upload any new FitNotes CSV export later using the file picker on the same page.

## Features at a glance

| Feature              | Description                                      |
|----------------------|--------------------------------------------------|
| Log                  | Add sets with date, weight, reps or time/distance |
| History              | All past workouts grouped by day                 |
| Charts               | Line graphs for any strength exercise            |
| Exercises            | Add new exercise types anytime                   |
| Gamification         | XP from volume, levels, streaks, badges          |
| Data                 | Import FitNotes CSV / Export JSON backup         |

Enjoy tracking and improving!
